System design overview

PeoplePay360 Backend Architecture

A modular HR and payroll backend that separates request handling, security, business rules, data access, and external document delivery.

Next.js API Routes Prisma ORM MySQL JWT + bcrypt Zod Puppeteer Nodemailer

Request lifecycle

Every protected endpoint follows the same backend processing pattern.

1Request

The frontend calls a Next.js API route.

2Authenticate

The JWT is read and the active user is loaded.

3Authorize

The user’s role or record ownership is checked.

4Validate

Zod verifies fields, types, dates and allowed values.

5Process

A route, service or rule engine executes the operation.

6Respond

Prisma saves data and the API returns JSON or PDF.

Business modules

The backend is separated by business domain so each feature remains independently understandable and maintainable.

Authentication

Passwords, JWT sessions, active-user checks and role-based access.

Employees

Employee records, reporting managers, employment status and associated data.

Working schedules

Daily shifts, break periods and calculated weekly working hours.

Attendance

Check-ins, check-outs, worked-hour calculation and manual correction history.

Contracts

Effective employment periods, wages and salary-structure assignment.

Time off

Leave types, allocations, balance validation and approval workflows.

Salary configuration

Structures and ordered fixed, percentage or formula-based salary rules.

Payroll

Payrun creation, employee calculation, validation, warnings and payment.

Payslip delivery

Detailed payslip records, PDF generation and individual email delivery.

Controlled payroll lifecycle

A payrun must move through defined states so calculation, verification and payment remain separate operations.

DRAFT

The period, salary structure and employees are selected.

COMPUTED

Contracts, attendance and salary rules produce payslips.

VALIDATED

Bank, PAN and contract checks pass without warnings.

PAID

A payroll manager finalizes the payrun and payslips.

Architecture summary: Next.js routes receive and secure requests, shared utilities provide consistent validation and responses, domain services execute HR and payroll rules, Prisma performs transactional database access, and specialized services generate and deliver payslips.
